# JavalinExample

Учебный проект на Java с использованием веб-фреймворка Javalin.

## Технологии

- **Java** — основной язык программирования
- **Gradle** — система сборки
- **Javalin** — легковесный веб-фреймворк
- **JTE** — шаблонизатор
- **JUnit 5** — фреймворк для тестирования

## Запуск

```bash
./gradlew run
```

Приложение будет доступно по адресу: http://localhost:7070

## Тесты

```bash
./gradlew test
```

## Структура проекта

```
src/main/java/org/example/hexlet/   — исходный код
src/test/                            — тесты
gradle/                              — конфигурация Gradle
```

## Зависимости

Версии зависимостей управляются в файле `gradle/libs.versions.toml`.
